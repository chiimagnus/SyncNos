description: 先保存一条内容，再按需要阅读、同步或导出。

1. [安装 SyncNos](/docs/install/)
2. 打开一个 AI 对话、网页文章或 YouTube / Bilibili 视频
3. 从 Popup 或页内入口保存当前内容
4. 到[本地库](/docs/library/)确认结果

第一次使用不需要连接任何外部服务。
