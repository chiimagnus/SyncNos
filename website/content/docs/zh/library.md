## 浏览和搜索

保存过的 AI 对话、网页文章和视频都会出现在本地库中。

使用搜索定位条目，打开详情后可以继续阅读完整内容。

## 详情操作

条目详情提供与当前内容相关的操作，例如：

- **复制完整 Markdown**
- **打开原始链接**
- 已同步时，直接打开对应的 Notion、Obsidian、飞书或 GitHub 目标
- 对支持复制链接的同步目标，复制远端页面链接

## 图片缓存

详情页的**更多**菜单会显示图片数量和缓存状态。

需要把剩余图片保存到本地时，选择**缓存图片**即可。图片失败不会删除已经保存的正文。
