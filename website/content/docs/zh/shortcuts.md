## SyncNos 内部快捷键

打开 **SyncNos → 设置 → 快捷键**，可以为导航、筛选、当前条目的复制与导出、评论以及朗读设置快捷键。

1. 搜索要使用的操作，点击右侧的键位按钮。
2. 按下想设置的组合键。如有冲突，先修改已有绑定。
3. 使用 **×** 清空键位，或点击 **恢复默认** 重置设置。

macOS 默认包含：打开设置 `⌘⇧,`、切换侧边栏 `⌘\`、切换上一条/下一条 `⌘⌥↑/↓`，
以及复制原始链接 `⌥⇧L`、导出 JSON `⌥⇧J`。
Windows 和 Linux 使用 Ctrl 代替 ⌘、Alt 代替 ⌥。

切换上一条/下一条只在当前已加载的会话间进行，不会自动加载更多内容。
快捷键只在 SyncNos Popup 或标签页内生效，不会在输入框、编辑器或弹窗中触发。

## 浏览器快捷键

打开 Popup、保存当前页面和打开 SyncNos 标签页的快捷键由浏览器管理。
在 **设置 → 快捷键** 中点击 **管理快捷键**，前往浏览器设置。浏览器快捷键默认未分配键位。

如果快捷键没有生效，请检查当前操作是否可用、键位是否冲突；浏览器或系统保留的组合键不能覆盖。
