---
title: 快捷键
description: 设置浏览器和 SyncNos 内部快捷键，并排查无法触发的问题。
---

打开 **SyncNos → 设置 → 快捷键**。两类快捷键的设置方式不同。

## 浏览器快捷键

用于打开 Popup、保存当前页面或打开 SyncNos 标签页。默认不分配按键。

设置页会显示浏览器当前绑定的按键；点击 **管理快捷键** 前往浏览器的扩展快捷键管理页。如果浏览器不支持直接跳转，请在浏览器设置中手动打开。

## SyncNos 内部快捷键

用于侧边栏、收藏列表、详情工具栏、阅读器等操作，只在 SyncNos Popup 或标签页内生效。

1. 搜索操作，或展开对应分组。
2. 点击该操作右侧的键位按钮，按下要使用的组合键；录制时会实时显示已按下的键。
3. 键位保存后即可使用。若与其他操作冲突，提示会出现在该操作旁，可直接重录。

已设置的键位旁始终显示 **×**，点击即可清空。按 **Esc** 取消录制；**恢复默认** 可一次还原所有内部键位。

例如，侧边栏默认使用 macOS 的 `⌘ + \`（Windows / Linux 为 `Ctrl + \`）。按键显示会适配系统，不区分左右修饰键；**Backspace** 和 **Delete** 也可以设置为快捷键。

**复制 Markdown** 只有一个快捷键：在列表中复制当前条目，在详情中复制当前打开的内容；双栏模式根据键盘焦点确定目标。

**导出**与**同步**只为操作菜单提供快捷键；具体导出格式、同步平台在菜单中选择。阅读器的排版、主题、朗读设置通过更多菜单调整，播放/暂停、停止朗读仍可设置快捷键。

悬停图标按钮时，当前快捷键会在提示文字下方以较浅颜色显示。

## 快捷键没有生效？

- **浏览器快捷键**：检查浏览器是否已分配该按键；这类键位不能直接在 SyncNos 内编辑。
- **内部快捷键**：确认焦点位于 SyncNos Popup 或标签页内，且当前操作可用；输入框、编辑器和弹窗内不会抢占按键。
- **录制失败**：查看操作旁的冲突提示，重新选择键位。单独的 **Tab** 留给焦点导航，**Esc** 用于取消录制；浏览器或系统已占用的组合键、部分硬件键也可能无法触发。
