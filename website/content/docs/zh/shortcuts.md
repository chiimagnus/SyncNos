打开 **SyncNos → 设置 → 快捷键**。

## SyncNos 内部快捷键

可配置的操作只包括：

- **常用操作**：打开设置、展开／收起侧边栏、上一条／下一条会话。
- **筛选**：打开来源筛选；查看网页来源时还可打开域名筛选。
- **阅读器**：播放／暂停朗读（仅文章或视频的阅读内容可用）。
- **会话详情**：复制原始链接、Notion／飞书／GitHub 链接；打开原始页面、Notion／Obsidian／飞书／GitHub 页面；复制完整 Markdown；导出 Markdown／JSON；打开／关闭评论侧边栏。

不为「更多」、返回、数据概览、列表的批量按钮或阅读器排版按钮另设快捷键。详情操作只作用于**当前打开的会话**，不会操作批量选中的条目。链接不存在、操作被禁用或详情尚未准备好时，不会拦截按键。上一条／下一条按当前列表的顺序切换已加载的会话；到达首尾不循环，也不会自动翻页。

1. 搜索操作或展开分组。
2. 点击右侧键位按钮，按下希望使用的组合键。
3. 如有冲突，在对应操作下修改；点击 **×** 可清空，**Esc** 取消录制，**恢复默认** 清除自定义绑定。

默认键位：**设置 `⌘ + ⇧ + ,`**、**侧边栏 `⌘ + \\`**、**上一条 `⌘ + ⌥ + ↑`**、**下一条 `⌘ + ⌥ + ↓`**、**复制原始链接 `⌥ + ⇧ + L`**、**导出为 JSON `⌥ + ⇧ + J`**。Windows／Linux 上使用 Ctrl 代替 ⌘、Alt 代替 ⌥。其余操作默认不分配键位。

图标按钮的 Tooltip 在较弱的第二行显示快捷键；复制目标及详情「更多」菜单在操作名称右侧显示键位。未分配时不显示键位。执行复制快捷键后会显示成功反馈。

## 浏览器快捷键

打开 Popup、保存当前页面、打开 SyncNos 标签页仍使用浏览器原生 Commands 配置。点击 **管理快捷键** 打开浏览器快捷键设置；SyncNos 不保存或编辑这类键位。

## 无法触发？

快捷键仅在 SyncNos Popup 或标签页内生效，不会抢占输入框、编辑器和模态弹窗。请确认当前操作可用、键位未冲突。浏览器或系统拦截的组合键无法由扩展强制覆盖。
