---
title: 功能总览
description: 快速了解保存之后还能在 SyncNos 里做什么。
---

采集只是第一步。下面这些功能都可以直接基于本地库使用，不要求先连接外部同步服务。

| 功能 | 适合做什么 |
| --- | --- |
| [本地库](/docs/library/) | 搜索、阅读、复制完整 Markdown、打开原始页面和已同步目标 |
| [浏览器快捷键](/docs/capture/#浏览器快捷键) | 打开 Popup、保存当前页面，或打开 / 聚焦 SyncNos 应用；键位由浏览器管理 |
| [划线与评论](/docs/comments/) | 在网页文章中保存引用、高亮、评论和回复 |
| [阅读、朗读与大纲](/docs/reader/) | 调整文章/视频排版和主题、朗读内容、快速跳转长内容 |
| [$ 插入](/docs/dollar-mention/) | 在支持的 AI 输入框中搜索并插入本地条目 |
| [数据概览](/docs/insights/) | 查看本地采集数量、趋势、来源分布和常用内容 |
| [导出与备份](/docs/export-backup/) | 导出 Markdown / JSON，或创建可恢复的 Backup |

如果要把内容持续写入外部服务，进入[同步](/docs/sync/)。
