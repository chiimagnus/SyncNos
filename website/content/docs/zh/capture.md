## 浏览器快捷键

SyncNos 提供三项快捷操作：**打开 Popup**、**保存当前页面**、**打开/聚焦 SyncNos 应用**。

默认不分配键位。到 **设置 → 快捷键** 查看当前绑定，或进入浏览器自己的扩展快捷键设置进行修改。

## 插件内部快捷键

在 **SyncNos → 设置 → 快捷键** 中，可以为收藏列表、来源/站点筛选、详情工具栏、更多菜单和阅读器操作设置快捷键。

- 可以搜索操作名称或快捷键，并按导航、收藏列表、详情和阅读器分组查看；点击键位开始录制，正在按下的键会实时显示。
- 支持字母、数字、标点、空格、回车、Tab、退格、删除、方向键、导航键、数字键盘及 F1–F24 等；支持 `Command`、`Control`、`Option/Alt` 和 `Shift`，不区分左右。单独的 `Tab` / `Esc` 保留给键盘导航与取消录制，修饰键须与其他键配合。
- 按钮右侧的 `×` 清空键位，`Esc` 取消录制；`Delete` 和 `Backspace` 现在可以直接录为快捷键。重复或跨平台冲突的组合会提示冲突，也可以恢复默认键位。
- 键位按当前系统显示：macOS 使用 `⌘`、`⌥`、`⌃`、`⇧`，Windows 使用 `Ctrl`、`Alt`、`Win`，Linux 使用 `Ctrl`、`Alt`、`Super`。普通的主修饰键（`Mod`）在 macOS 为 `⌘`，在 Windows / Linux 为 `Ctrl`。
- 常用操作仍提供默认值，如 `Alt+Shift+B` 切换侧边栏、`Alt+Shift+F` 打开来源筛选、`Alt+Shift+M` 打开详情更多菜单。只在 SyncNos Popup 或应用内生效；在输入框、编辑器和弹窗中不会抢占键盘。系统/浏览器拦截的快捷键无法由插件强行接管，某些媒体键、`Fn` 或电源键也可能不会传递给网页。

鼠标悬停图标按钮时，Tooltip 在功能说明下方以较浅的文字单独显示当前快捷键；文字已经说明用途的菜单项仅提示已绑定键位。设置齿轮不再重复提示“打开设置”。

## 图片

AI 对话和网页文章可以缓存内容图片。图片获取失败不会阻断正文保存；已有条目可在详情页 **更多 → 缓存图片** 重试。
