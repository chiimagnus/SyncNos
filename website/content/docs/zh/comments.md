该功能用于网页文章。

![文章评论侧栏](/assets/product/comments-discussion.png)

## 打开评论

打开已保存的文章，在详情右上角选择 **评论**。支持的当前网页也可以从页内入口直接打开。

## 保存引用和评论

选中文章原文后，可以直接保存引用，也可以同时写评论。长引用、多行引用和不同的鼠标选择方式都会按正文内容处理。

后续评论直接回复在同一组内容下。删除第一条内容会删除整组；删除后续评论只删除该条。

`Ctrl/⌘ + Enter` 可以提交。

## Markdown 与公式

评论和回复支持常用 Markdown，公式沿用文章与聊天的排版。行内公式使用 `$...$`，独立公式使用 `$$...$$`：

```text
行内公式：$E=mc^2$

$$
\frac{1}{1+x}
$$
```

图片语法显示为文字或链接，不会加载图片或作为评论附件同步；原始 HTML 按文本显示。

选中文章得到的引用预览只显示文本，不重新解析 Markdown 或公式。
