---
title: 划线与评论
description: 在网页文章中保存引用、评论和回复。
---

该功能适用于网页文章。

![文章评论侧栏](/assets/product/comments-discussion.png)

## 使用方法

1. 打开已保存的文章，点击右上角的 **评论**。支持的网页也可以直接使用页内评论。
2. 选中文章原文，保存引用或添加评论。
3. 在已有引用或评论下继续回复。

按 `Ctrl/⌘ + Enter` 可以提交评论。

删除一组评论的第一条会删除整组；删除后续回复只影响该条内容。

## 输入格式

支持常用 Markdown 和数学公式（行内 `$...$`、独立 `$$...$$`）。
图片语法不会将图片作为评论附件上传。
