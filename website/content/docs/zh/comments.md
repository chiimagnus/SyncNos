该功能用于网页文章。

![文章评论侧栏](/assets/product/comments-discussion.png)

## 打开评论

打开已保存的文章，在详情右上角选择 **评论**。支持的当前网页也可以从页内入口直接打开。

## 保存引用和评论

选中文章原文后，可以直接保存引用，也可以同时写评论。长引用、多行引用和不同的鼠标选择方式都会按正文内容处理。

后续评论直接回复在同一组内容下。删除第一条内容会删除整组；删除后续评论只删除该条。

`Ctrl/⌘ + Enter` 可以提交。评论支持常用 Markdown 和 `$...$` / `$$...$$` 数学公式。

Markdown 图片不会作为评论附件加载或同步，原始 HTML 也不会作为 HTML 执行。
