## 文章和视频阅读器

打开已保存的网页文章或视频，在详情页右上角的**更多**菜单中可以使用阅读工具。

### 文本与排版

可以调整：

- 衬线 / 无衬线 / 等宽字体
- 字号、行高、正文宽度和字间距
- 左对齐或两端对齐

### 主题

阅读器支持跟随系统、浅色、护眼、深色和纯黑主题。

### 朗读

可以使用浏览器的 Web Speech，也可以配置 AI 朗读端点。朗读支持语速、声音和播放位置控制。

朗读过程中点击正文句子，可以从对应位置继续播放。

## 大纲导航

- **网页文章 / 视频**：正文存在标题结构时会显示阅读大纲，适合快速跳转长内容
- **AI 对话**：详情页提供独立的对话大纲，按用户轮次快速跳转

AI 对话目前不使用文章/视频的排版、主题和朗读工具。
