---
title: 同步概览
description: 把本地内容同步到 Notion、Obsidian、飞书或 GitHub。
---

同步是可选的；不连接外部服务也可以正常使用 SyncNos。

## 选择目标

| 目标 | 适合场景 |
| --- | --- |
| [Notion](/docs/sync/notion/) | 数据库和页面 |
| [Obsidian](/docs/sync/obsidian/) | 本地 Markdown vault |
| [飞书](/docs/sync/feishu/) | 飞书云文档 |
| [GitHub](/docs/sync/github/) | Markdown 仓库 |

每个目标都支持手动同步，并可单独开启自动同步。本地内容始终保留在 SyncNos。

只想拿到文件或做恢复时，使用[导出与备份](/docs/export-backup/)。

同步失败不会删除本地内容；修复连接或权限后重新同步即可。
