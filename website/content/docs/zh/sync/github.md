## 连接

1. 打开 **SyncNos → 设置 → GitHub**。
2. 点击 **Connect** 完成授权。
3. 按提示为需要的账号或仓库安装 SyncNos GitHub App。
4. 选择仓库和分支。
5. 点击 **Test**。

如果空仓库尚未初始化，先使用 **Initialize repository**。

## 同步与断开

连接成功后可以手动同步或开启自动同步。SyncNos 会把 Markdown 和附件写入所选仓库与分支。

**Disconnect** 只断开 SyncNos 中的连接；撤销 GitHub 授权或卸载 App 需要到 GitHub 操作。

## 遇到问题

- 看不到仓库：检查 GitHub App 的仓库权限后刷新列表。
- 没有写权限：确认 App 和当前账号都能写入目标仓库。
- 找不到分支：选择已存在的分支或默认分支。

同步失败不会删除本地内容。
