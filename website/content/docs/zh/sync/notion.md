## 连接

1. 打开 **SyncNos → 设置 → Notion**。
2. 点击 **Connect** 完成授权。
3. 选择 **Parent Page**。
4. 手动同步一次，确认写入正常。

需要时再开启自动同步。SyncNos 只能访问你授权给它的内容。

## SyncNos 管理的内容

SyncNos 会在 Parent Page 下创建或使用自己的内容数据库。正常使用不需要手工修改数据库字段或 section。

更换 Parent Page 后，后续同步会写入新目标。

## 断开与排障

**Disconnect** 会断开当前连接；彻底撤销授权需到 Notion 的连接设置中操作。

同步失败不会影响本地内容，修复连接后重新同步即可。
