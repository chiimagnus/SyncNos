## 支持的平台

| 平台 | 保存方式 |
| --- | --- |
| ChatGPT | 手动保存 |
| Gemini | 可自动保存 |
| Google AI Studio | 手动保存 |
| DeepSeek | 可自动保存 |
| Kimi | 可自动保存 |
| 豆包 | 可自动保存 |
| 元宝 | 可自动保存 |
| Poe | 可自动保存 |
| Notion AI | 可自动保存 |
| z.ai | 可自动保存 |

ChatGPT 和 Google AI Studio 使用虚拟列表，完整历史不一定同时存在于页面中，因此不参与自动保存。

## 手动保存

1. 打开目标对话，并切换到要保存的线程。
2. 在 SyncNos Popup 中选择**抓取 AI 对话**，或使用右键菜单的**保存当前 AI 对话**。
3. 回到[本地库](/docs/library/)确认对话和消息。

对支持自动保存的平台，可在**设置 → 通用 → 自动保存**开启后续消息的自动保存。

## ChatGPT 高级采集

ChatGPT 默认使用**页面采集**。高级采集是一个可选模式，可以在**设置 → 通用 → ChatGPT 高级采集**中开启。

它不是“更完整模式”，而是另一种采集来源：

|  | 默认页面采集 | 高级采集 |
| --- | --- | --- |
| 读取内容 | 以页面实际加载和显示的内容为准 | 以 ChatGPT 已保存的当前会话分支为准 |
| 更适合 | 尽量保留页面中已经展开的 thinking / progress | 稳定识别当前分支和消息，保存长对话 |
| 主要限制 | 页面没有加载或展开的内容可能无法保存 | ChatGPT 可能没有保留页面曾经显示过的完整 thinking / progress |

如果你更在意**完整的思考过程**，建议保持高级采集关闭，并在保存前展开需要保留的 thinking。

如果你更在意**稳定的会话结构和当前分支**，可以开启高级采集。引用会转换为可读链接，图表等富内容只保存适合长期阅读的文字信息。

正在生成的回复可以先保存为部分结果，生成完成后再次保存即可更新。高级采集失败时不会自动改用页面采集；关闭高级采集后重新保存即可。

当页面中还没有可保存的消息时，SyncNos 会显示“等待消息”，而不是报错。

## 图片与本地复用

AI 对话图片可以自动缓存到本地；关闭自动缓存后，正文仍然可以保存。

保存完成后，还可以使用[$ 插入](/docs/dollar-mention/)把本地条目重新插入支持的 AI 输入框。
