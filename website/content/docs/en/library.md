## Browse and search

AI chats, web articles, and videos appear in the local library. Search for an item and open it to read the full content.

## Detail actions

The detail view shows actions that fit the item and its sync state, such as:

- Copy full Markdown
- Open the original page
- Open or copy a synced destination link
- Enter comments, reader tools, or other relevant features

## Keyboard navigation

Use [Settings → Keyboard shortcuts](/docs/en/shortcuts/) for next/previous items, copying Markdown or the original link, and exporting or deleting the **current item**. These actions do not modify multi-selection; bulk export, sync, and delete remain in the existing selection toolbar.

## Image cache

The **More** menu shows image-cache status. Choose **Cache images** when needed; image failures do not remove saved text.
