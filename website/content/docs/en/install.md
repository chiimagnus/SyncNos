## Choose your browser

| Browser | Install from |
| --- | --- |
| Chrome, Arc, Brave, and other Chromium browsers | [Chrome Web Store](https://chromewebstore.google.com/detail/syncnos-webclipper/hmgjflllphdffeocddjjcfllifhejpok) |
| Microsoft Edge | [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/syncnosaiweb-clipper/ijkpghlfmkbjcgafapjcjahaikmnjncl) |
| Firefox | [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/syncnos-webclipper/) |
| Safari (macOS / iOS) | Build from the [SyncNos source](https://github.com/chiimagnus/SyncNos) with Xcode |

Once installed, SyncNos can capture locally without connecting any external sync service.

In browsers that expose a native extension Options / Preferences entry, that entry opens the SyncNos Settings page directly.

## Confirm the install works

1. Open the SyncNos extension.
2. Visit an AI conversation, web article, or YouTube / Bilibili video you want to save.
3. Capture the current page from the popup or in-page entry point.
4. Open the saved item in SyncNos and confirm the title and body / conversation / transcript look correct.

See [Capture content](/docs/en/capture/) for source-specific save behavior.

## Need AI-agent access?

You do not need the CLI for ordinary browser use.

When you want an AI agent to use SyncNos, see [CLI & AI SKILL](/docs/en/cli/).
