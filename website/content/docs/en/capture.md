SyncNos saves content to the [local library](/docs/en/library/) first.

![SyncNos Popup](/assets/product/popup-screenshots.png)

## Choose a content type

- [AI chats](/docs/en/capture-ai-chats/)
- [Web articles](/docs/en/capture-articles/)
- [Videos](/docs/en/capture-videos/)

When you reopen a previously captured page, a **locate icon** appears beside the popup's capture button. Select it to view the saved item in the popup and return to the list when done. The capture button remains available to refresh the content. The icon only means a local record exists, not that it is complete or current.

Image download failures do not affect saved text. Retry from **More → Cache images** in the detail view.

For faster access, see [Keyboard shortcuts](/docs/en/shortcuts/).
