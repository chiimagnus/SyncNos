## Browser shortcuts

SyncNos provides three browser actions: **open the popup**, **save the current page**, and **open/focus the SyncNos app**.

No keys are assigned by default. Use **Settings → Keyboard shortcuts** to see the current bindings or open the browser's extension shortcut settings.

## In-app shortcuts

Open **SyncNos → Settings → Keyboard shortcuts** to configure actions in the library, source/site filters, detail toolbar, More menu, and reader.

- Some common actions have defaults, such as `Alt+Shift+B` to toggle the sidebar, `Alt+Shift+F` for the source filter, and `Alt+Shift+M` for the detail More menu.
- Click a binding and press a new combination. `Delete` / `Backspace` clears it; `Escape` cancels. You can also restore all defaults.
- Unassigned actions can be configured too. Duplicate shortcuts are rejected.
- These keys work only inside the SyncNos popup or app, not across browser tabs. They do not trigger while typing in inputs or editors. Browser/system-reserved shortcuts may be unavailable.

## Images

AI chats and web articles can cache content images. Image failures do not block text capture; existing items can retry from **More → Cache images**.
