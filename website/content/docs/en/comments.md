This feature is for web articles.

![Article comments sidebar](/assets/product/comments-discussion.png)

## Open comments

Open a saved article and choose **Comments** in the upper-right actions. Supported current
article pages can also open the sidebar in place.

## Save quotes and comments

Select article text, then save the quote by itself or add a comment at the same time. Long,
multi-line, and different mouse-selection styles are handled as article text.

Later comments stay in the same group. Deleting the first item removes the group; deleting a
later comment removes only that comment.

`Ctrl/⌘ + Enter` submits.

## Markdown and math

Comments and replies support common Markdown and use the same math layout as articles and
chats. Use `$...$` for inline math and `$$...$$` for display math:

```text
Inline math: $E=mc^2$

$$
\frac{1}{1+x}
$$
```

Image syntax appears as text or links; images are not loaded or synced as comment attachments.
Raw HTML appears as text.

Quote previews from article selections remain text; Markdown and math are not reinterpreted.
