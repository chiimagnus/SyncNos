This feature is for web articles.

![Article comments sidebar](/assets/product/comments-discussion.png)

## Open comments

Open a saved article and choose **Comments** in the upper-right actions. Supported current article pages can also open the sidebar in place.

## Save quotes and comments

Select article text, then save the quote by itself or add a comment at the same time. Long, multi-line, and different mouse-selection styles are handled as article text.

Later comments stay in the same group. Deleting the first item removes the group; deleting a later comment removes only that comment.

`Ctrl/⌘ + Enter` submits. Comments support common Markdown and `$...$` / `$$...$$` math.

Markdown images are not loaded or synced as comment attachments, and raw HTML is not executed as HTML.
