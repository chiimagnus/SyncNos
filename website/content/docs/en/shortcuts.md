## In-app shortcuts

Open **SyncNos → Settings → Keyboard shortcuts** to assign keys for navigation,
filters, copying and exporting the current item, comments, and narration.

1. Search for an action, then click its key binding.
2. Press your preferred key combination. If it conflicts, change the existing binding first.
3. Use **×** to clear a binding or **Restore defaults** to reset.

macOS defaults include: Settings `⌘⇧,`, sidebar `⌘\`, previous/next conversation `⌘⌥↑/↓`,
copy original link `⌥⇧L`, and export JSON `⌥⇧J`.
Use Ctrl instead of ⌘ and Alt instead of ⌥ on Windows and Linux.

Previous/Next only moves through loaded conversations and does not load more entries.
In-app shortcuts work inside the SyncNos popup or tab, not while typing in inputs, editors, or dialogs.

## Browser shortcuts

The browser manages keys for opening the popup, saving the current page, and opening the SyncNos tab.
In **Settings → Keyboard shortcuts**, click **Manage shortcuts** to open the browser's shortcut settings.
These keys are unassigned by default.

If a shortcut does not work, check that the action is available and that there are no conflicts.
Browser or system-reserved key combinations cannot be overridden.
